# 高德优先、隐私同意与坐标隔离

为改善国内地点搜索和逆地理编码的可用性，v0.2.1 在用户明确同意后优先使用高德搜索 SDK；未配置密钥、拒绝或撤回同意、超时或查询失败时沿用系统 Geocoder → Nominatim，并始终允许手动填写。首次启动先展示中文隐私说明，再申请相机与位置权限；设置页允许重新选择，同意状态在每次请求时检查，SDK 使用前按顺序调用 `updatePrivacyShow` 和 `updatePrivacyAgree`。

高德查询及返回值使用 GCJ-02，在高德适配层与 WGS-84 相互转换，应用有效值、水印、EXIF 与天气继续使用 WGS-84，避免供应商坐标偏移泄漏到成片和天气。输入提示没有坐标时仍展示候选地点，点选后按 POI ID / 地址补全，过期结果和手动坐标编辑保持受保护。
